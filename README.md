# TADC-RolAdventure
Este es un juego de rol interactivo basado en *The Amazing Digital Circus*; los personajes —Caine, Gangle, Zooble, Kinger, Ragatha, Jax y Pomni— deben sobrevivir y evitar perder sus vidas si quieren terminar el juego, escapar de ahí y regresar al circo digital.
